# AWS VPC 3-Tier Architecture

## Project Overview
A secure and scalable 3-tier web application architecture using AWS.

## AWS Services
- Amazon VPC
- Public and Private Subnets
- Internet Gateway
- NAT Gateway
- Route Tables
- Amazon EC2
- Application Load Balancer
- Target Groups
- Amazon RDS MySQL
- Security Groups

## Architecture
1. Web Layer
2. Application Layer
3. Database Layer
